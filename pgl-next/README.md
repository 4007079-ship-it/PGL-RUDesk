# PGL-RUDesk (своя версия)

Удалённый доступ на собственном коде, без кода RustDesk. Разрабатывается
отдельно от текущей версии в папке `pgl-next/`; старая версия продолжает
работать, пока эта не будет готова.

## Состав

- `cmd/pgl-server/` — сервер на VPS: аккаунты, список устройств, сигнализация
  соединений и встроенный ретранслятор (TURN).
- `internal/` — общий код.
- `web/` — управление из браузера.

Соединение экрана, мыши, клавиатуры, буфера обмена и файлов строится на
WebRTC (библиотека pion). Используются только библиотеки с лицензиями MIT и
BSD.

## Сборка

Нужен Go 1.24. Локально:

    cd pgl-next
    go build ./...

Сервер запускается на `127.0.0.1:21200` (меняется переменной `PGL_LISTEN`).
Проверка: `GET /health`.

## Статус

Первый этап. Готова основа сервера с проверкой здоровья.
