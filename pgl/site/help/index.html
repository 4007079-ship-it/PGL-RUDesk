Конфиденциальность

PGL-RUDesk работает только через собственный сервер. Сторонние облака и чужие серверы не используются.

  • Изображение экрана, ввод, файлы и буфер обмена передаются между устройствами в зашифрованном виде. Если прямое соединение невозможно, данные идут через ретранслятор нашего сервера, но остаются зашифрованными, и сервер их не видит.
  • На сервере хранится: ID устройства, имя компьютера и версия программы. Если вы зарегистрировались, то ещё почта, пароль в виде хеша, список ваших устройств и история входов.
  • Данные не продаются и не передаются третьим лицам.
  • Почта используется только для входа и восстановления пароля.

Linux: нужен сеанс X11

В сеансе Wayland удалённое управление работает с ограничениями. Для полноценной работы войдите в сеанс X11 (Xorg):

  1. Выйдите из системы.
  2. На экране входа выберите пользователя и нажмите на шестерёнку в углу.
  3. Выберите «Ubuntu на Xorg» (или «GNOME на Xorg»), затем войдите.

Проверить текущий сеанс можно командой:

echo $XDG_SESSION_TYPE

Должно быть x11.

Linux: экран входа на Wayland не поддерживается

Чтобы подключаться к компьютеру, пока на нём никто не вошёл, экран входа тоже должен работать на X11. Для GDM (Ubuntu, Debian) выполните:

sudo sed -i 's/^#\?WaylandEnable=.*/WaylandEnable=false/' /etc/gdm3/custom.conf
sudo reboot

В Fedora этот файл называется /etc/gdm/custom.conf.

Linux: SELinux блокирует службу

В Fedora, CentOS и RHEL SELinux может мешать службе PGL-RUDesk. Чтобы разрешить ей работать, выполните:

sudo ausearch -c 'pgl-rudesk' --raw | audit2allow -M pgl-rudesk
sudo semodule -i pgl-rudesk.pp
sudo systemctl restart pgl-rudesk

Для быстрой проверки можно временно отключить SELinux командой sudo setenforce 0. После перезагрузки он включится снова.

Linux: ввод с клавиатуры в Wayland

В сеансе Wayland PGL-RUDesk передаёт нажатия клавиш через виртуальную клавиатуру системы. Другие программы на удалённом компьютере могут видеть набираемый текст, в том числе пароли. Поэтому программа спрашивает разрешение перед включением ввода.

Разрешайте ввод только на компьютерах, которым доверяете. Самый надёжный вариант — сеанс X11.

macOS: разрешения

Чтобы к Mac можно было подключиться, PGL-RUDesk нужны три разрешения. Откройте Системные настройки → Конфиденциальность и безопасность и включите PGL-RUDesk в разделах:

  1. Запись экрана — чтобы показывать экран;
  2. Универсальный доступ — чтобы управлять мышью и клавиатурой;
  3. Мониторинг ввода — чтобы передавать нажатия клавиш.

После этого перезапустите PGL-RUDesk. Если программы нет в списке, добавьте её кнопкой «+» из папки «Программы».
